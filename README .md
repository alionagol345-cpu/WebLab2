## 📝 Опис проєкту
Додаток розроблений для зручного керування часом та планування розкладу користувача. У рамках поточної роботи статичний інтерфейс було перетворено на повноцінний клієнт-серверний додаток.

### Основні функції:
* **Авторизація:** Реєстрація нових користувачів та вхід до системи.
* **Профіль:** Перегляд та редагування персональних даних (ім'я, email, стать, дата народження).
* **Керування будильниками:** Створення, редагування, видалення та зміна статусу (увімк./вимк.) будильників.
* **Приватність:** Список будильників прив'язаний виключно до поточного авторизованого користувача.
* **Сповіщення:** Відстеження часу в реальному часі та видача повідомлення (alert) при досягненні часу спрацьовування.

## 🛠 Технологічний стек
* **Frontend:** Vue.js (v3), Bootstrap 5 (UI).
* **Backend:** Node.js, фреймворк Express.js.
* **База даних:** SQLite для збереження інформації.
* **Зв'язок:** Axios для асинхронних запитів до API.

## 📂 Архітектура (VueJS-компоненти)
Логіка Vue.js розділена на незалежні компоненти-представлення (Views) для кожної сторінки:

1. **RegisterView (`register.html`):** Реєстрація користувача, двостороннє зв'язування даних через `v-model`.
2. **LoginView (`login.html`):** Автентифікація та збереження об'єкта користувача у `localStorage`.
3. **ProfileView (`profile.html`):** Відображення та редагування особистих даних (режими перегляду/редагування).
4. **AlarmListView (`index.html`):** Головний компонент для CRUD-операцій з будильниками. Містить метод `checkAlarms`, який викликається кожну секунду.
5. **AboutView (`about.html`):** Довідкова інформація та логіка перевірки активної сесії.
